# Jogo do Galo

Jogo do galo (tic-tac-toe) para jogar no browser, feito em HTML, CSS e JavaScript sem dependências.

- Modo 2 jogadores no mesmo dispositivo
- Modo contra o computador (algoritmo minimax — o computador nunca perde)
- Pontuação de vitórias e empates

## Jogar

Abre o `index.html` no browser, ou joga online através do GitHub Pages.
